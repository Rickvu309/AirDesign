# The theme draws a field's invalid edge once, and no component draws its own

`tests/theme-tokens.test.ts` › "draws one invalid edge from the theme, and no component draws its own" wants the rule in `packages/theme/src/tokens.css` that outlines an `[aria-invalid="true"]` control, or a `[data-focus-ring]` field holding one, in `--danger-text` at the control's radius, and turns `--focus-ring` red so the focus ring agrees. It fails when a `.tsx`, `.css` or `.astro` file under `apps/web/src` or `apps/site/src` styles an invalid edge itself (`aria-invalid:` ring, border, shadow or outline classes, `has-[[aria-invalid…`, or an `invalid && "…danger…"` class). Two rounds of the Link field drew an inset red shadow that its chevron covered, leaving a box around the chevron and a second edge inside the focus ring. A field shows an invalid state by setting `aria-invalid` and nothing else.
