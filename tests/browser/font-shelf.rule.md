# A browser test never downloads a font while it runs: the preview server serves fonts only from the shelf it filled before it started

`tests/browser/font-preview.mjs` fills the shelf, `~/.cache/airdesign/fonts`, with every family in `shelvedFamilies` (`tests/browser/font-shelf.mjs`) before it prints its port, so a failed download stops the run at the start and names the family. It then serves through a `FontSource` whose network is `offShelf`, which refuses every download and says which family to add to the list, so a font a test needs and the shelf lacks fails every run instead of only when GitHub is slow. `fontMiddleware` takes that `FontSource` and asks no other network: `apps/api/src/platform/font-route.test.ts` serves a shelved family with the network refusing and wants one refused download for a family the shelf lacks. The verify stack (`.agents/skills/verify-airdesign/bin/serve.mjs`) hands `createApi` a `FontSource` on the same shelf through its `fonts` option, so in a browser run `design-states.spec.ts` reads what the preview server filled (a journeys run, which starts no preview server, still fills the shelf on first use); the second case of `font-route.test.ts` serves the API's route from that option with the network refusing. ci keeps the shelf in the `font-shelf-` cache, keyed by the font catalog and the list, so a run downloads only when either changes.
