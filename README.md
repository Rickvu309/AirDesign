# AirDesign design source

- `AirDesign.pen`: the design file (Pencil format). It loads `fonts/`, `images/`, `landing-assets/`, `shaders/` and `motion-assets/` by relative path, so keep those folders beside it.
- `refs/`: reference screenshots (editor, Vietjet).
- `lunagraph/`: Lunagraph export (components, compositions, Page 1 screens).
- `unreferenced/`: loose exports that `AirDesign.pen` does not load (embedded images, generated images, landing cursor/caret files). Safe to move or delete.
