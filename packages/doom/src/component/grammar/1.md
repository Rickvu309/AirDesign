# Component spec, grammar 1

A component is a template the deck keeps as a JSON spec. AirDesign expands it, with an instance's data, into ordinary layers inside one frame. Coordinates are pixels inside that frame: 0,0 is its top left; use `frame.w` and `frame.h`. A slide is 1920 by 1080.

Add one with the `airdesign_execute` operation, Doom's change `{"op": "component", "spec": {...}}`; the answer names its id. Place it with `{"op": "add", "kind": "component", "slide", "component": id}`, and change an instance with `{"op": "set", "target": instance, "data"}`. Update it with `{"op": "component", "target": id, "spec": {...}}`: send the whole spec. Every instance is rebuilt in the same edit from its own data. Read one with `airdesign_execute get {"component": id}`; built-in ids such as `column` can be read as worked examples.

## Spec

```json
{
  "version": 1,
  "name": "Progress bars",
  "collections": { "rows": { "label": "string", "share": "nonnegative" } },
  "defaults": { "bar": { "var": "accent1" }, "track": { "var": "background2" }, "ink": { "var": "text" } },
  "variants": { "values": [true, false] },
  "defaultVariant": { "values": true },
  "let": [
    ["rowH", ["div", ["get", "frame.h"], ["max", 1, ["count", ["get", "data.rows"]]]]],
    ["barX", 380],
    ["barW", ["sub", ["get", "frame.w"], 460]]
  ],
  "parts": [
    { "repeat": { "over": ["get", "data.rows"], "as": "r" }, "let": [["top", ["mul", ["get", "i"], ["get", "rowH"]]]],
      "emit": { "kind": "text", "key": ["list", "label", ["get", "r.id"]], "x": 0, "y": ["get", "top"], "w": 360, "h": ["get", "rowH"],
        "chars": ["get", "r.label"], "style": "body", "color": ["get", "token.ink"], "align": "left", "alignV": "center", "fit": { "smaller": 20 } } },
    { "repeat": { "over": ["get", "data.rows"], "as": "r" }, "let": [["mid", ["mul", ["add", ["get", "i"], 0.5], ["get", "rowH"]]]],
      "emit": { "kind": "rect", "key": ["list", "track", ["get", "r.id"]], "x": ["get", "barX"], "y": ["sub", ["get", "mid"], 8], "w": ["get", "barW"], "h": 16, "fill": ["get", "token.track"] } },
    { "repeat": { "over": ["get", "data.rows"], "as": "r" }, "let": [["mid", ["mul", ["add", ["get", "i"], 0.5], ["get", "rowH"]]]],
      "emit": { "kind": "rect", "key": ["list", "bar", ["get", "r.id"]], "x": ["get", "barX"], "y": ["sub", ["get", "mid"], 8],
        "w": ["mul", ["get", "barW"], ["min", 1, ["get", "r.share"]]], "h": 16, "fill": ["get", "token.bar"] } },
    { "repeat": { "over": ["get", "data.rows"], "as": "r" }, "when": ["get", "variant.values"], "let": [["top", ["mul", ["get", "i"], ["get", "rowH"]]]],
      "emit": { "kind": "text", "key": ["list", "value", ["get", "r.id"]], "x": ["sub", ["get", "frame.w"], 64], "y": ["get", "top"], "w": 64, "h": ["get", "rowH"],
        "chars": ["format", ["get", "r.share"], { "scale": 0.01, "digits": 0, "prefix": "", "suffix": "%", "sign": "negative" }],
        "style": "label", "color": ["get", "token.ink"], "align": "right", "alignV": "center", "fit": "omit" } }
  ],
  "sample": { "w": 1200, "h": 360, "data": { "rows": [ { "id": "a", "label": "Design", "share": 0.8 }, { "id": "b", "label": "Build", "share": 0.45 } ] } }
}
```

| Field | Meaning |
| --- | --- |
| `version` | Always 1, this grammar. |
| `name` | Up to 200 characters. |
| `collections` | Up to 16 named tables of rows. Each declares up to 16 fields. Every row also has an `id` (letters, digits, `_`, `-`, up to 32), unique in its table. A row must hold exactly its declared fields and `id`. Up to 100 rows per table; `collectionLimits` sets a lower cap per table, such as `{"rows": 8}`. |
| `defaults` | Tokens: name to a string, number, boolean or colour. An instance may override each one with a value of the same type. |
| `variants`, `defaultVariant` | Optional. Variant name to its list of choices (strings or booleans), and the default choice for each. |
| `let` | Optional named values, `[[name, expression], ...]`, evaluated in order. A later one may use an earlier one. |
| `parts` | The layers to emit, below. |
| `sample` | `{w, h, data}`: a frame size and data that expand cleanly. AirDesign checks the spec by expanding it, and places a new instance at this size when no box is given. Required on add; an update without one keeps the current sample. |

Field types:

| Type | Value |
| --- | --- |
| `"string"`, `"string?"` | Text; `?` also allows null. |
| `"number"`, `"number?"` | Any number; `"number?"` allows null, for a missing value. |
| `"positive"`, `"nonnegative"` | A number above 0, or at least 0. |
| `"color"`, `"color?"` | A colour, below; `?` also allows null. |
| `["good", "bad"]` | An enum: one of up to 32 strings. Use one for a yes/no or good/bad flag. |
| `"ref:<table>"` | A row id in another table. |
| `{"list": type}`, `"number?[]"`, `"color?[]"` | A list of values of that type. |
| `{"optional": type}` | The field may be left out of a row. |

## Expressions

A number, string, boolean or `null` is itself. An object is evaluated field by field. A list is a call: `[operator, ...arguments]`. A list value is written `["list", a, b]`.

| Form | Result |
| --- | --- |
| `["get", "a.b.c"]` | A value in scope, then its fields. `["field", record, "name"]` reads one field of a computed record. |
| `["if", cond, yes, no]` | `cond` must be a boolean. Only the chosen branch is evaluated. |
| `["map", list, "x", body]`, `["filter", list, "x", body]`, `["every", list, "x", body]` | Each item is `x` and its index `i`. `filter` keeps items whose body is `true`; `every` is `true` when every body is. |
| `["scan", list, "x", seed, step, output]` | A running total. `acc` starts as `seed`; `step` gives `next`; `output` may read `x`, `i`, `acc` and `next`. |
| `add` (any count), `sub`, `mul`, `div` (nonzero divisor), `sqrt`, `floor`, `hypot`, `pow10`, `round` | Arithmetic. `["round", n, digits]` rounds without formatting; `["pow10", d]` is 10 to the power d. |
| `min`, `max` | Of numbers or lists of numbers. Give an empty list a fallback: `["max", 1, list]`. |
| `sum`, `count` | Of a list. |
| `eq`, `lt`, `isInteger` | Booleans. For greater-than, swap: `["lt", b, a]`. For not: `["if", c, false, true]`. |
| `coalesce` | `["coalesce", v, fallback]`: v, or the fallback when v is null. |
| `concat` | Joins strings and numbers into text, up to 512 bytes. |
| `at`, `cycle`, `lookup` | `["at", list, index]`, or `null` outside it; `["cycle", list, index]` wraps around; `["lookup", record, key, fallback?]`. |
| `linear` | `["linear", v, lo, hi, a, b]` maps v from lo..hi to a..b. |
| `band` | `["band", i, count, start, span, share]` gives `{start, size}` for slot i of count across span; share (0..1) of each slot is filled, centred. |
| `format` | `["format", n, {"scale", "digits", "prefix", "suffix", "sign"}]`: all five fields; sign is `"negative"` or `"always"` (adds `+`). Shows n divided by scale. Uses the deck's number locale. |
| `decimals`, `resolutionDigits` | `["decimals", values, scale]`: 1 when small values need a decimal, else 0. `["resolutionDigits", step]`: the digits a step needs. |
| `point`, `site` | Line ends: `["point", x, y]`, or `["site", key, "t" | "r" | "b" | "l" | "c"]` to attach to an emitted shape. |
| `polyline`, `wedge`, `discs`, `polar` | Path data in the unit square: `["polyline", [points]]`; `["wedge", center, inner, outer, fromTurn, toTurn]`; `["discs", points, rx, ry]`. `["polar", center, radius, turn]` gives a point. |
| `textWidth`, `textMetrics`, `textExtent`, `fitSize` | Measured text: `["textWidth", chars, style, size?]`, `["textMetrics", chars, style]` gives `{w, h}`, `["textExtent", chars, style, size?]`; `["fitSize", size]` turns `"auto"` into the theme's smallest size. |
| `flowText` | `["flowText", items, {width, rows, rowHeight, leading, gap, style, smaller}]` flows labelled items into rows, as a legend does: `{items: [{item, x, row, w}], rows, size}`. |
| `readableInk`, `contrast-ink`, `contrastTint`, `contrastGrey` | Colours by contrast: `["readableInk", fill]` black or white; `["contrast-ink", fill, a, b]` the clearer of a and b; `["contrastTint", fill, background, ratio]`; `["contrastGrey", background, accent, step, preferred, minimum]`, a tint of the step's theme colour. |
| `includes`, `matchingFocus`, `rampSlots`, `rampFold`, `rampCapacity`, `paletteRamp`, `unique-colors` | Series colours: an accent for the focused ids and neutral shades for the rest, as the built-in charts use; `["includes", list, value]` tests membership, `rampCapacity` is how many colours the theme tells apart, and `rampFold` sums the rest as Other. Read `column` and `stacked` for their use. |
| `sortBy`, `groupBy`, `group-by`, `index-by`, `flatten`, `partition`, `runs`, `sample`, `split-ranked`, `allocate`, `startsWithWordIgnoreCase`, `index-key` | Lists: `["sortBy", rows, field, ...]` ascending; `["groupBy", rows, field]` a record of groups, `["group-by", rows, field]` a list of groups; `["index-by", rows, field]` a record by id; `flatten` joins lists; `["partition", list, size]`; `runs` splits at nulls; `["sample", list, count]` spreads picks; `["split-ranked", rows, field, count]` gives the top count and the rest; `["allocate", weights, total]` whole numbers that sum to total; `["startsWithWordIgnoreCase", text, prefix]`; `["index-key", i]` a key from an index. |
| `axis`, `timeCategory` | `["axis", lo, hi, ticks]` gives a rounded `{lo, hi, step, ticks}`; `["timeCategory", label]` is true for a date or quarter label. |
| `place-boxes`, `nonoverlap`, `sector-space`, `hierarchy`, `link-channels` | Placement helpers the built-in charts and diagrams use: label boxes that avoid obstacles, dropping overlaps, room in a pie sector, a tree of rows with `id` and `parent`, and connector lanes between cards. Read `pie`, `tree` or `architecture` for their use. |
| `advise` | `["advise", code, note, about?]` reports advice as a finding and returns `true`. Put it in an `if`. |

There is no `and`, `or`, `not` or `gt`: nest `if` and swap `lt`.

## Scope

| Name | Value |
| --- | --- |
| `data.<table>` | The instance's rows, each with `id` and its fields. |
| `token.<name>` | A default or the instance's override. |
| `variant.<name>` | The chosen variant. |
| `frame.w`, `frame.h` | The frame size. |
| `focus` | The ids an instance's `focus` names. |
| `i`, `acc`, `next` | Set by `repeat`, `map`, `filter`, `every` and `scan`. |

`data`, `token`, `frame`, `variant`, `i`, `acc` and `next` are reserved names.

## Parts

A part is `{ "emit": {...} }` or `{ "children": [parts] }`, with optional `"repeat": {"over": list, "as": "name"}` (sets the name and `i`), `"let"` and `"when"` (a boolean; false skips the part). A `children` part may add `"group": key`, which puts its layers in one frame, such as a card with the text on it. Up to 64 parts per level and 32 levels.

Keep the JSON shallow, as in the example: one `emit` per part, each with its own `repeat`, and name computed values in `let` instead of nesting expressions. Deep `children` and long nested expressions are where brackets go wrong.

Every emit has a `key`: a list of 1 to 5 ids that names the layer for as long as its data lives, such as `["list", "bar", ["get", "r.id"]]`. Keys must be unique in one expansion; build them from row ids, not positions. A person's changes to a layer stay with its key when the data changes.

| `kind` | Fields |
| --- | --- |
| `rect` | `key, x, y, w, h, fill`, optional `stroke: {color, width}`, `radius` |
| `text` | `key, x, y, w, h, chars, style, color, align, alignV`, optional `fit`, `fill`, `stroke`, `radius`, `padding`, `size`, `overflow: "ellipsis"` |
| `line` | `key, start, end, color, width, route, arrow`, optional `dash` |
| `path` | `key, x, y, w, h, d`, optional `fill`, `stroke: {color, width}`, `fillStroke` |
| `finding`, `notice` | `key, message`: report a finding instead of a layer, such as when the data cannot be shown. Put it in a part with `when`. |

- A colour is `"#RRGGBB"` or a theme colour `{"var": name}` with optional `"tint"` from -1 (darker) to 1 (lighter). Theme colours: `text`, `text2`, `background`, `background2`, `accent1` to `accent6`, `link`, `positive`, `negative`, `total`. Prefer theme colours so the deck's theme restyles the component.
- `style` is a theme text style. Sizes in the default theme, in px: `display` 88, `bigNumber` 80, `title` 56, `heading` 40, `body` 32, `body2` 28, `caption` 24 and `label` 24 (bold). A text box needs a height of at least 1.25 times its size per line. `size` sets a size in px instead, without `fit`.
- `align` is `left`, `center`, `right` or `justify`; `alignV` is `top`, `center` or `bottom`. `chars` is text; `\n` starts a new paragraph.
- `fit`: `{"smaller": size}` lets the text shrink to that size and wrap to two lines; add `"group": name` so a set of labels shares one size, and `"thin": gap` to show every k-th label when they cannot all fit. `"omit"` leaves out a text that does not fit. Any text that does not fit is reported as a finding.
- A dot or circle is a `path` with `"d": "M0 0.5A0.5 0.5 0 1 0 1 0.5A0.5 0.5 0 1 0 0 0.5Z"`: path data spans 0 to 1 of its box.
- `route` is `straight`, `elbow` or `curve`; `arrow` is `none`, `arrow`, `triangle` or `circle`; `width` is in px.

## Limits

A spec holds at most 12,000 parts and expression terms and 32 KB of JSON. One expansion may use 80,000 work units and emit at most 499 layers. A deck holds at most 32 components. An update that rebuilds more instances than one edit can carry is refused: detach or delete some instances.

## Errors

A refused spec names the first fault: `field` is its JSON path in the change, such as `spec.parts[0].children[1].emit.w`, and the note says what that place needs. Fix that place and send the spec again. Findings, such as a text that does not fit or a layer outside the frame, do not refuse the spec; the answer's note names each one by its layer key. Fix them in the spec before you finish.

When an update changes a collection's fields, every instance's rows must change too: put the `component` change first and then a `set` with the new `data` for each instance, in the same edit. Changes apply in order, and instances are rebuilt at the end of the edit.
