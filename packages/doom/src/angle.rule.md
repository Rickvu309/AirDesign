# A rotation an agent sends, on an add or a set, is stored as the canvas's rotate handle stores it: wrapped onto 0 up to 360 in tenths of a degree, from one `wrapRotation`, and an add that takes a rotation or a flip writes it

`packages/doom/src/agent-structure.test.ts` sets a rotation of 400, -90, 12.34 and 359.97 through the agent reader and fails unless the box holds 40, 270, 12.3 and 0, and adds a shape, line, frame (plain and grid), icon, text (new box and filling empty title and subtitle placeholders), picture and a chart component with a rotation and a flip and fails unless each box holds them; `packages/doom/src/agent-patterns.test.ts` fails unless a matrix's rotated axis label stores 270; `packages/doom/src/angle.test.ts` fails unless `wrapRotation` never returns 360 or -0; `packages/mcp/src/server.test.ts` sends both shape and title-placeholder adds over the protocol and fails unless the read shows `r=270`
