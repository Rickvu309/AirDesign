# A field refusal names the true path, the fault, and that field's accepted form

`packages/doom/src/field-refusal.test.ts` reads refused edits and fails unless each names the field path, the fault, and either that field's accepted form, the condition it needs, or the kind of layer or slide that takes no such field. A form is the value the field accepts. It is not a parent key list, schema prose, or a condition such as a line. A condition is `needs`. A kind comes from `kindFields`, the one list of the fields each kind takes. `packages/agent/src/field-refusal.test.ts` sends the audit's empty hidden caption, an empty batch, a bad call and a layer-kind refusal through `airdesign_execute` and fails unless the note names the same detail. `readIntent` returns that detail from the read that failed. A refusal with no path stays the generic sentence.
