# Pick a layout

Before you build a slide, name its purpose, find it below and build the layout it points to from the `layouts` skill. The purpose comes from the title: what must the reader see to believe it?

| The slide's purpose                                         | Layout                   |
| ----------------------------------------------------------- | ------------------------ |
| One number carries the point                                | L1 One number            |
| Two to four headline numbers, and what explains them        | L2 Numbers over evidence |
| A value over time: growth, burn, cash, a target missed      | L3 Trend                 |
| Which items are biggest: segments, countries, causes        | L4 Ranking               |
| From one total to another: a bridge of gains and losses     | L4 Ranking, as a bridge  |
| Two or three options, before and after, us against a rival  | L5 Options               |
| Risks, recommendations, next steps, initiatives with owners | L6 Item rows             |
| Many values per item, such as prices per plan               | L6 Item rows, as a table |

- The title slide's title states the deck's answer, as every title does: "Mid-size Europe is big enough to be our second market", not the deck's subject.
- A timeline, a process or an architecture has no layout yet: build it from the `kit` skill's pieces, filling the body area as the slide guide says.
- When no row fits, the slide makes two points. Split it.
- When the same layout comes up three times in a row, check each slide makes its own point. Merge the ones that repeat.
- Keep the title, its place and the source line the same on every content slide, whatever the layout.
