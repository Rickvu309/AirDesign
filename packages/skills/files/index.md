# AirDesign skills

Call `airdesign_read_skill` with a skill name to read its guide.

- `execute`: How to read and change a deck with `airdesign_execute`: the script, every operation, layer kinds, colours, text and layout. Read it before your first call.
- `slides`: How to design a slide: priorities, sizes, filling the slide, numbers and the check after each slide. Read before you design.
- `avoid`: Habits that make slides look machine-made. Read before you design.
- `picker`: From a slide's purpose to its layout. Read it before you build each slide.
- `layouts`: Six slide layouts with their grid in pixels, how much each holds and the kit pieces each uses.
- `kit`: Ready slide pieces drawn from plain layers that you copy into a slide and own. Read it before you draw a piece from scratch.
- `review`: The checks to run on every slide before you stop.
