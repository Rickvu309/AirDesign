# An agent learns what a slide paints wrong without an open tab: every edit and read answer measures the slides it touched with the deck's own fonts on the server, lists at most ten overflow, overlap, line-crosses-text, off-slide and small-text problems, names the texts whose letters the fonts lack instead of calling the layout clear, says when the layout is clear or why it went unchecked, and never refuses or fails a landed edit

`packages/agent/src/problems-answer.test.ts` lands an edit that covers a title's words and fails unless the answer names the overlap, reads a deck and fails unless it lists just the layout problem and the painted sizes, fails unless a clear layout, a text with letters the fonts lack, and each unchecked reason (fonts, time, a fault, including a fault while working out the touched slides) say so in the note, and fails unless a twelfth problem is counted rather than listed

Doom gives each problem as a code, its layer and its numbers, and the agent writes the words: `problemNote` in `packages/agent/src/problem-words.ts` words every code, and `gridNeeds` in `packages/agent/src/answer.ts` words a grid too tight for its box. `packages/agent/src/problem-words.test.ts` fails unless each code, and each kind of tight grid, reads as its sentence.
