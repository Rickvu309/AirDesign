# An agent learns what a slide paints wrong without an open tab: every edit and read answer measures the slides it touched with the deck's own fonts on the server, lists at most ten overflow, overlap, off-slide and small-text findings, names the texts whose letters the fonts lack instead of calling the layout clear, says when the layout is clear or why it went unchecked, and never refuses or fails a landed edit

`packages/mcp/src/layout-findings-answer.test.ts` lands an edit that covers a title's words and fails unless the answer names the overlap, reads a deck and fails unless it lists just the layout finding and the painted sizes, fails unless a clear layout, a text with letters the fonts lack, and each unchecked reason (fonts, time, a fault, including a fault while working out the touched slides) say so in the note, and fails unless a twelfth finding is counted rather than listed
