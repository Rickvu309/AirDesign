# What enforces each gesture rule

The rules for the editor's gestures, split from `CHECKS.md`. A gesture is a key press or a pointer move with the keys and the place it works (`GLOSSARY.md`).

| Rule                                                                                                                                                        | Enforced by                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every gesture in the editor has one row in the gesture table and a browser test                                                                             | `apps/web/src/gesture-coverage.test.ts` reads every `tests/browser/*.spec.ts` and fails for each row of `gestures` in `packages/render/src/gestures.ts` that no `covers(...)` call names, and for a `covers(...)` id that is not a row. `packages/render/src/gestures.test.ts` fails when a press of one row reads as another row where both work |
| Every key the editor acts on is a row of the gesture table; a key read anywhere else belongs to one control (a field, a list, a slider, a menu, typed text) | `apps/web/src/gesture-keys.test.ts` scans `apps/web/src` and `packages/render/src` and fails on a key read outside `gestures.ts` that is not listed for its control file, on a listed key a file no longer reads, and on a row with keys whose id no handler names                                                                                |
| A drag paints once a frame and leaves the filmstrip and design panel alone until it lands                                                                   | `tests/browser/drag-feel.spec.ts`; its `drag-frame` and `drag-delay` warn over their limit                                                                                                                                                                                                                                                        |
