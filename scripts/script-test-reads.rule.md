# A script test that reads a repo file by path runs when that file changes

`scripts/script-test-reads.mjs` scans each `scripts/*.test.mjs` for the repo paths it reads: a quoted path or a run of joined segments that sits within three lines of a file-reading call, or that a `const` holds and a reading call uses. The names must be tracked files, folders at least two levels deep outside `apps` and `packages`, or a file name with an extension, which keeps a deleted file linked. A name only passed as a sample, a test or spec file, and an import are no link. `scripts/change-map.mjs` turns on the `scripts` part for a file a test reads, so ci runs them, and `pnpm prove` plans those tests, so `pnpm gate` and the recheck in `pnpm land` run them with no list to keep (`scripts/script-test-reads.test.mjs`, which replays the size limits on AGENTS.md and ci.yml that PR 1036 missed)
