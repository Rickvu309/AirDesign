# A Vitest hook does not import the catalog barrel or a namespace import of Doom

`scripts/hook-heavy-import.mjs`, tested by `scripts/hook-heavy-import.test.mjs`, fails a `beforeAll`, `beforeEach`, `afterAll` or `afterEach` whose dynamic import reaches a value import of `@airdesign/catalog`, or `import * as` from `@airdesign/doom` that the file never calls. The actions panel's hook did both, for a type and for icon names, and that import crossed Vitest's 10 second hook limit when `apps/web/src` started in parallel. Import a type, or `@airdesign/catalog/icon-names`, instead of the barrel. A namespace the file calls, a named Doom import, and a namespace beside a named Doom value stay in the hook, because that value already loads Doom and the DOM has to exist before React loads.
