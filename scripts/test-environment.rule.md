# A test starts without the variables that pick a repository or a provider, so it gives one answer in an agent shell, a person shell and ci

The repository selectors (`GIT_DIR`, `GIT_WORK_TREE`, `GIT_COMMON_DIR`, `GIT_INDEX_FILE`, `GIT_OBJECT_DIRECTORY`, `GIT_ALTERNATE_OBJECT_DIRECTORIES`) point a scratch repository's git at the wrong repository when a hook, `git rebase --exec` or `git bisect run` exports them, and `ANTHROPIC_`, `CLAUDE_`, `CODEX_`, `OPENAI_` and `CLAUDECODE` come from the agent's own session. `scripts/test-environment.mjs` names them. Every vitest project loads `scripts/vitest-clean-environment.mjs`, `scripts/tooling-tests.mjs` starts each script test with `cleanEnvironment`, and the `globalSetup` in `tests/browser/launch.ts` calls `stripInherited` before Playwright starts its workers. `scripts/test-environment.test.mjs` starts a script test with `GIT_DIR` set to another repository and checks its commit lands in its own, starts vitest with the variables set and runs `tests/clean-environment.test.ts`, and fails when a vitest project, the runner or the launch drops the strip
