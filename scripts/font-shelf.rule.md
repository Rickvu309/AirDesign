# A browser test or journey never downloads a font while it runs: fonts come from a shelf filled before the first page opens

`scripts/font-shelf.mjs` holds the shelf, `~/.cache/airdesign/fonts`, and `shelvedFamilies`. `tests/browser/font-preview.mjs` fills the shelf with every listed family before it prints its port, then serves through a `FontSource` whose network is `offShelf`, which downloads nothing and logs the family to add to the list, so a font a test needs and the shelf lacks fails every run instead of only when GitHub is slow. The verify stack (`.agents/skills/verify-airdesign/bin/serve.mjs`), which `design-states.spec.ts` and journeys start, fills the same shelf before it starts the API and hands that `FontSource` to `createApi` as `fonts`; a family off the list still downloads there, since agents name fonts freely. `createApi` holds one `FontSource` for its font route and for the MCP layout check (`servedFontMetrics`), so both read the same fonts; the test API in `tests/browser/api-stack.ts` and `layout-agreement.spec.ts` measure through the shelf with `offShelf`. `apps/api/src/platform/font-route.test.ts` serves a shelved family through `fontMiddleware` and through the API's route with the network refusing, and `font-metrics.test.ts` wants the layout check to ask the source it was given. ci's `.github/actions/playwright` keeps the shelf in the `font-shelf-` cache, keyed by the font catalog and the list, for the browser and design parts and for journeys.
