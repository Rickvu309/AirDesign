# A local test run never writes a timing record; only `pnpm timings` does, in a pull request that changes nothing else

Local browser, unit and journey runs measure into an untracked `*.measured.json` beside `tests/browser/spec-seconds.json`, `tests/unit-seconds.json` and `tests/journeys/journey-seconds.json`, so a test run leaves the tree clean. `pnpm timings` folds the measures into the records. The `timings` step refuses a diff from a freshly fetched `origin/main` (`knowsMain` in `scripts/checked.mjs`) that changes a record beside any other file, and names the record and `pnpm timings`. A pull request that deletes a test leaves the records alone: `cited-paths` does not read them, and the next `pnpm timings` drops the deleted file's name. `timings.test.mjs` replays PR 1463 at 0b38eaf and a branch rebased past a stale `origin/main`, `browser-timings.test.mjs` and `unit-shards.test.mjs` hold the untouched record
