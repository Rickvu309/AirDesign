# Text names only code that exists: every repo path a doc, rule file, script, config, workflow or command cites, every file and name a spec covers, and every line the glossary allows

The `cited-paths` step (`scripts/cited-paths.mjs`) reads each tracked `.md` file's code spans and relative links, each repo path in a non-test script, config, `.yml` or `.sh` file, including commands such as `node scripts/<name>.mjs` in `package.json`, `.github/actions/ci-changes/pptx-paths.txt`, the allowed lines of `tooling/oxlint-plugin-airdesign/glossary.json` and every `specs/<topic>/covers.json`, and fails each one that names a file, folder or declaration the repo no longer has, with its file and line. In a script or config, a quoted repo path with no file extension is a folder when it ends in `/`, such as `packages/mcp/` in `scripts/areas.json`, and a prefix otherwise, such as the one that ends in `usage-` there: the folder must exist, and some file or folder path must start with the prefix. A path resolves only from the repo root or from the citing file's folder, so a moved file fails; a bare file name resolves beside the citing file or when exactly one file has it. URLs, globs, placeholders and paths into a folder git ignores, such as `dist` or `node_modules`, are not citations. Fixtures, ADRs and the red-main drill record the past and are not read. Nor are the timing records `tests/unit-seconds.json`, `tests/browser/spec-seconds.json` and `tests/journeys/journey-seconds.json`: they are measured data that only `pnpm timings` writes, and it drops the names of deleted files, so a pull request that deletes a test leaves them alone. `scripts/cited-paths.test.mjs` replays the stale lines that ddc433a68, 4aeae03dc, 730385c96, 47ece2d72 and 9b95e2a96 fixed by hand, the name PR 1409's move made ambiguous, the pricing folder that 95d815a94 deleted while `scripts/areas.json` kept it, and a deleted unit test that the timing records may still name.
