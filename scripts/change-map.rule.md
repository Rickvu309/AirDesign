# A change runs every CI part it can affect, and a change the map cannot place runs everything

`scripts/change-map.mjs` turns a list of changed paths into the parts that must run: `source` with the unit test folders, `scripts`, `design`, `browser`, `journeys`, `pptx`, `corpus` and `model-check`. The graph is the workspace packages from `pnpm-workspace.yaml` and their manifests, plus the imports of every code file outside a package. A changed path reaches its package or file and everything that imports it. Docs run only `source` and `scripts`, whose checks read them. `pptx` and `corpus` follow `.github/actions/pptx-changed/paths.txt`. Any `package.json`, the lockfile, CI config, the check runner, shared test setup, a path no part owns, a diff that cannot be read, and `--full` run everything (`scripts/change-map.test.mjs`)
