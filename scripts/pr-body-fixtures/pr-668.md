## What changes

Drag a number field’s label in the design panel to change its value: one step per two pixels, tens with Shift, tenths with Alt. One Undo restores the value before the drag.

A refused value stops at the last accepted value. Typing, arrow keys and the field’s accessible name stay available. Mixed fields do not scrub.
