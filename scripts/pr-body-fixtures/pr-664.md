## What changes

A font size typed in the text toolbar is now kept when focus leaves the field. Before, only Enter applied it, and pressing Tab or clicking elsewhere threw the typed size away without a word, while the Design panel's number fields already kept a valid draft on blur. Enter and blur now share one commit, so Enter followed by blur applies the size once. Escape still cancels, and Escape followed by blur applies nothing. An invalid draft is still not applied.

From the product UI audit (finding F4, editor tools), judged with the `better-ui` and `better-accessibility` skills: one editable value should not have two commit rules.

## Proof

- `apps/web/src/editor/format-buttons.test.tsx`: type then Tab, type then click elsewhere, Enter then blur (one commit), Escape then blur (no commit), and an invalid draft.
- `tests/browser/text-style.spec.ts`: in the real editor, typing a size and pressing Tab changes the selected text's size.
- `pnpm land --check` passed on this commit (the push guard refuses an unstamped commit).
