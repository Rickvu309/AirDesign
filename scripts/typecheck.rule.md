# Every TypeScript file the repo ships or tests is in a project `pnpm typecheck` builds

`scripts/typecheck.mjs` builds the root `tsconfig.json` (tests, Playwright and Vitest configs, `.railway`, script sources) and every project under `apps/` and `packages/`, composite or not, then fails before `tsc` runs when a tracked `tsconfig*.json` or `.ts`, `.tsx`, `.mts` or `.cts` file is outside them. A project beside an `expect.json` is a boundary fixture that must fail, and `pnpm check:boundaries` runs it. `scripts/typecheck.test.mjs` holds this for the repo. The gate runs typecheck in its first phase, before the affected build, since both write `dist`. On main at f35449658, 709 of 1,581 TypeScript files were outside it: `apps/web` and `apps/site` were left out for not being composite, and `tests/` had no project, so a web type error first showed in the web build and 58 type errors in tests, configs and `.railway/railway.ts` showed nowhere
