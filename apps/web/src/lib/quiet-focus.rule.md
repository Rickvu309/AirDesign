# A control rings only once Tab has moved focus

`apps/web/src/lib/quiet-focus.test.ts` and `tests/browser/deck-name-header.spec.ts` › "the deck name shows no ring after a rename by click, and rings once Tab reaches it" hold this. `quietFocusUntilTab` marks the page `data-quiet-focus` from the start and on every pointer press, and clears the mark on Tab. The one ring rule in `packages/theme/src/tokens.css` skips buttons, links and other controls while the mark is there. Text fields keep their ring. Focus that code moves after a click, such as back to the deck name after Enter or to a menu's trigger after Escape, used to ring in blue, and each case got its own opt-out: the canvas, the Ask Aira box, the deck menu, the shape tray. `tests/theme-tokens.test.ts` fails a component that quiets its own ring. Leave focus alone and the page decides.
