# Every control of Doom's design panel is live in every layer: its words, a write to the layer, the paint, the undo and an agent

`apps/web/src/trait-parity.test.ts` reads every control `nodeModel` shows for a text, shape, line, icon, picture and frame layer. Each control wants a label and words for every option. Some value of it must write the layer through `changeWrites`, land in `applyEdit`, change what `resolveSlide` paints, and come back whole through `invert`. Each property it writes must be one an agent's `set` change writes too. `writesNothingOnDoom`, `paintsNothing` and `personOnlyOnDoom` name the exceptions, and each list fails once its entry no longer holds, so it can only shrink. `apps/web/src/color-parity.test.ts` holds that every colour an agent sends lands from the panel's picker on the same property, and that the picker's template colour, tint and typed hex land in every colour control. `apps/web/src/control-kinds.test.ts` wants a component and a `tests/browser/control-<kind>.spec.ts` for every control kind a field uses, inside a union, a record or a list too
