# A cropped picture keeps its aspect when it is resized, unless Control or Fn is held

`apps/web/src/editor/transform-drag.ts` scales the box of one picture whose image fit is crop and whose crop window is set. The crop fractions stay, so the bitmap does not stretch, and `readForAgent` still prints that crop. Control or Fn (`breakAspect`) is the resize that changes the aspect. Shift still keeps a shape's proportions. `apps/web/src/editor/transform-drag.test.ts` fails when an ordinary resize stretches the box or the crop read changes. `tests/browser/editor-crop.spec.ts` fails when that resize is not one undo.
