# Template interactions

The Design button opens the S43.01 template picker beside the saved editor. Your templates precede the Light and Dark basics. Search preserves its query while selecting a version.

The S43.02 controls preview the selected version. Apply to this deck updates linked properties in one undo step and lists every retained local property. Insert new slide appends a slide and leaves the deck pin and existing slides intact. Imported master families stay separate in the selector. Missing fonts require a deliberate Geist substitution; fonts without embedding rights disclose the PowerPoint substitution risk.

Save template captures an immutable owner-scoped version. Make default pins that exact version for the next new deck. The current deck changes only on Apply. A newer saved version appears as an offer with Review; it never changes the deck automatically. Save, apply and default actions report pending, success and refusal states. Read-only and unsaved editors cannot apply changes.

Native exports carry the selected theme as a PowerPoint master and preserve original imported master/layout relationships. Local LibreOffice checks establish relationship closure only. Windows and macOS reopen/editability remain P09 X01 gates.
