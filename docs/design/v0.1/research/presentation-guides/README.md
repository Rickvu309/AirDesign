## Find and cite a passage

1. Choose a guide above and search its Markdown for the topic.
2. Cite its title and `PDF page NNN`. Page numbers include the cover and may differ from printed page numbers. Each page heading has a stable link, such as [Boardroom, PDF page 008](from-blah-to-boardroom.md#pdf-page-008).
3. Open the page image when the passage involves a chart, table, spatial grouping or OCR. The four-pillar framework on [Boardroom page 008](from-blah-to-boardroom.md#pdf-page-008), chart categories on [page 023](from-blah-to-boardroom.md#pdf-page-023) and table examples on [page 048](from-blah-to-boardroom.md#pdf-page-048) also have checked layout transcriptions.

## Conversion limits

- All 205 PDF pages have sections in their original order. Selectable text is converted to Markdown. Pages that lose words during formatting use a labeled plain-text transcription instead.
- Original page images accompany graphic pages and transcription fallbacks. Detected tables have supplemental cell transcriptions. Other diagram relationships still require the image.
- Text embedded in substantive raster images has supplemental local OCR. OCR can misread words, numbers and reading order. Verify it against the image before quoting it or deriving a rule.
- PDF web links and internal page links are listed beneath the relevant page. Their destinations were preserved; external availability was not checked.
- Purchaser watermarks are removed from the text transcription and remain visible in original page images. Copyright and beta notices are retained. The Superstar Analyst cover uses the title “What's Next for the Superstar Analyst?”; its source filename uses “Next Steps.”
- Original filenames and SHA-256 hashes appear in each Markdown file. The original PDFs are not duplicated here. Source wording, dated claims and recommendations belong to the author and have not been updated or adopted as project instructions.
