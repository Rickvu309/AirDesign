# AirDesign landing page concepts

## Basis for both concepts

These are two alternative pages. Each has seven main sections, plus navigation and a footer. Quoted lines are final visitor-facing copy. Visual directions are production instructions.

The source screens establish the editor, Aira panel, import progress, export dialog, and agent settings. The Halden revenue chart uses the values visible in S42.01. Additional storylines and Brightwater content below are proposed sample material, not customer evidence. Label both companies as examples.

Before publication, build the proposed sample decks in AirDesign and capture the actual output. Capture each import comparison from the same PowerPoint file before and after import. The supplied import screen shows progress, not a completed result. Do not present that screen as proof of fidelity. Use real slides in place of the gray placeholders in the supplied screens.

### Entry behavior for both pages

| Visible action | Destination after email sign-in |
| --- | --- |
| Start free | Open the new-deck flow with Aira. |
| Import a PowerPoint | Open the PowerPoint file chooser. |
| Use my own agent | Open agent setup with the chosen app retained. |
| Sign in | Open the owner's decks, or resume an existing intent. |

Retain the intent through email links, codes, resends, and account changes. Signed-in visitors go directly to the chosen flow. Reading a guide or pricing must not clear an existing intent. Preserve Claude or Codex context when a visitor arrives from that agent. These are routing requirements, not extra page copy.

Guides live under `/agents`, with separate Claude and Codex destinations. Use the same guide content in Settings, Agents. Provide a plain text version with the MCP address and connection entry point. The endpoint shown in the settings screen is `https://mcp.airdesign.app/mcp`.

Keep the first slide visible without starting a video. Load later captures on demand. On phones, stack comparisons vertically and keep slide text readable. Editing happens on a laptop or desktop.

## Recommendation

Choose concept A, with concept B's early PowerPoint comparison moved directly below the hero. The changing action title makes AirDesign's consulting standard visible at a glance, while the import comparison answers the practical question of what happens to an existing deck. Keep A's storyline, live editing proof, agent guides, export proof, and single free-plan card to complete the journey.
