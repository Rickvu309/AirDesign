# P03R reference evidence for P09 X01

Local OPC preservation proves bytes and graph invariants. It does not prove PowerPoint rendering, no-repair reopening, native editability, placeholder inheritance or line counts. P03R is an external evidence batch consumed by P09 X01. Missing references block release acceptance.

Use the committed [fixture manifest](../../../fixtures/pptx/manifest.json), the original fixtures and the lane outputs from the P03 report. Copy all inputs and outputs into the external pack with SHA-256 hashes and the implementation head. Never replace an input silently. Include the local relationship, source hash, security-removal and unresolved-font receipts.

Before captures, pin one Windows PowerPoint and one Mac PowerPoint installation: record OS version/build, architecture, application version/build, update channel, locale, display scaling, slide size and export settings. These values are pending; do not invent a pin. Obtain licensed font files for each requested family. Record exact file SHA-256, face/version, license source and installation on both hosts. Aptos is requested by the synthetic fixtures but is not bundled or licensed by this repository. Missing fonts keep visual checks blocked; no silent substitutions.

On each pinned installation:

1. Open original and round-trip files. Save real application screenshots and any repair dialog or repair log. Require no repair prompt and no missing relationships.
2. Match slides by stable identifiers. Capture original and output with identical geometry and settings. Require changed-pixel ratio at most 0.001 per slide and 0.01 per item, with unchanged text line counts. Keep raw images, per-item bounds, diff images, pixel counts and line-count observations.
3. Edit the first styled text run, one table cell and one chart value using native application controls. Save, close and reopen. Verify the edit, unrelated runs, chart workbook values and original shared dependency independently.
4. Check group placement, theme/master/layout references, inherited placeholder positions and text style, both slide-specific notes and opaque metadata. Keep screenshots and inspected output files.
5. Reopen the explicitly sanitized unsafe fixture. Verify removals match the security receipt and remaining relationships close. Keep macros, external links and active objects absent.

The batch index must include platform pins, font provenance, original/output hashes, no-repair verdicts, native-edit verdicts, each visual ratio and line-count result, and evidence paths. Keep every unsupported or unavailable case in `unproven.json`. Local LibreOffice, when available, is only a fast check and never satisfies any PowerPoint row.

The implementation owner prepares `~/tmp/airdesign-autopilot/P03/P03R/` with the fixtures, generated outputs, local receipts, this checklist and explicit pending platform/font/visual/editability records. The external owner fills the records at P09 X01 and retains failures in the acceptance denominator.
