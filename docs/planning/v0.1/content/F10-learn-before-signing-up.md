# F10 Learn before signing up

Show real slides and real PowerPoint results, explain credits plainly, and teach agents how to connect. Every intent survives sign-in.

New codes in F10: S13 Pricing, S14 Agent guides. S01 Landing is reused. Next free codes are S15 and X7.

## When something goes wrong

- Sent by an agent: lands on that app's guide.
- On a phone: can read, sign up and view decks. Editing is for a laptop or desktop in v0.1.
- Already signed in: intents go straight to the flow, as in F01.
- An agent reads the site: the plain text guide points to the MCP address and F06.

## Rules

- Show, do not tell: real slides and real import results.
- Prices in credits with examples, never tokens.
- Every intent survives sign-in.
- Guides are one source, shown on the site and in S08.
- Privacy-friendly analytics only. No ad trackers.
- v0.1 is desktop-first for editing.
- Target: the landing page usable in under 1 s.
