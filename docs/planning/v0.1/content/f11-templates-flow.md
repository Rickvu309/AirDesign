Templates, and how a look applies

Theme

Basic templates by AirDesign, free: Light slides and Dark slides. Ship with the product.

Template

The person's own templates: colors, fonts, logos and layouts. Saved from a PowerPoint or a deck, or built by an agent. Several templates. Each keeps its own history.

Applying a look

Only items linked to the look change. Items with their own style stay and are listed. One undo step. A deck keeps the version it applied; a newer version is offered, never forced.

When something goes wrong

PowerPoint with several masters

Each becomes a family of layouts. The person picks the main one.

Different slide size

Layouts adapt by their slots. Anything that does not fit is flagged.

Items with their own style

They stay as they are and are listed. An agent can link them to the template.

Template changes later

Decks using it are told a newer version exists. Nothing changes until someone applies it.

Template deleted

Decks keep the version they have. New decks use the AirDesign default.

Font with no right to embed

Used in AirDesign. Export flags it (F04).

An agent edits the template

Tagged like any change, in the template's own history, and undoable.

Rules

A look changes only what is linked to it. Content never moves or disappears.

Applying a look is one undo step.

Decks keep the template version they applied. Updates are offered, never forced.

Templates belong to the person and work across all their decks.

Templates are free. Agent help uses weekly usage, on either agent.

Both agents use get_brand and update_brand for templates. A look is applied as one change set. The person asks for new templates.

Target: a look applied to a 30-slide deck in under 2 s.
