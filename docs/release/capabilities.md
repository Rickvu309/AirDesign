# Release capability reference

This branch is a local release candidate. No deployment or external acceptance is implied.

| Capability | Local evidence | Release boundary |
| --- | --- | --- |
| First deck, shared edits, saved versions | P01–P08 checks; P09 first-deck and import/export probes | Public hosting remains X05 |
| Aira and tool mutations | Deterministic adapter replay, 144 quality paths and 120 tool trials | Real model quality, SDK conformance, and latency remain X03 |
| Quality acceptance | Frozen tasks, pinned previous task results, no-regression veto, calibration validator, swapped-order scoring, seeded bootstrap | Human baseline, 360 ratings, holdout and preference floor remain X04 |
| PPTX preservation and native export | Engine reopen, unchanged package bytes, local LibreOffice fast check | Windows and Mac reference applications, editable chart and text, masters and fonts remain X01 |
| Accessibility | Local keyboard, focus, reflow and contrast probes | Real NVDA and VoiceOver walkthroughs remain X02 |
| External agent guides | Proposed connection, pagination, stale recovery and revoke instructions | Each named client needs an authorized public HTTPS walkthrough under X05 |
| Weekly usage and credits | Ledger rates and fixture payment race checks | Country eligibility, FX, signatures and reconciliation remain X06 |
| Recovery | Ordered reconnect batches of at most 100 commands in one admitted transaction, immutable per-command receipts, concurrent locked outbox reads coalesced, durable checkpoint before queue deletion, offline reload and undo, disposable operation-store backup, restore, deletion, interrupted lease fencing | Production database backup, hosting and scheduling require an authorized deployment runbook |

Imports preserve supported package parts. Unsupported items can remain kept or flagged. Review warnings before editing and export. There is no lossless-export claim. The site offers synthetic before and after files with hashes. Their source deck demonstrates a text edit, not evaluated presentation quality.

No named client has a supported badge. Real model generation and vendor application compatibility are not release claims. No quality score is published. Share and Present are absent from the release surface.

Public copy is an exact allowlist in `apps/site/content/claims.json`. Each entry names a P01–P09 receipt or an explicitly unverified X01–X06 gate. The build reads allowance, rates and public amounts from the shipped ledger constants. Raw public amounts and unregistered copy fail lint. Reset pricing appears in Settings; the public pricing page explains the reset without an amount.

The landing uses sample chart and outline illustrations beside an actual built Studio capture. The outline is labeled as an illustration. The agent diagram describes connection preparation, with client verification still blocked on X05.
