# Planted faults in the typing check

The typing check is in [checks-undo.md](checks-undo.md#typing).

Planted faults. Each old behaviour PR 427 fixed, the notes wait PR 418 added, the notes record PR 441 pinned, and the notes field's own undo, put back in the model and then in the code:

| Old behaviour                                                                                                      | TLC on the planted model                                                                                                                                         | Replay on the planted code                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ctrl+Z in the box goes to the browser's own undo, which shows the first letter                                     | 18 states, `NeverPartOfNew`: TypeText, TypeText, KeyUndo                                                                                                         | `field` counts `[contenteditable]` as a form field: KeyUndo on the box fails, the key went to the browser                                                                             |
| Undo from the browser's menu runs in the box                                                                       | 21 states, `NeverPartOfNew`: TypeText, TypeText, MenuUndo                                                                                                        | `Passage` lets `history` input through: MenuUndo fails, the box let the browser undo                                                                                                  |
| The undo does not wait for records still landing                                                                   | 23 states, `NoUndoOnMissing`, and `TurnLands` without the ghost: TypeText, KeyUndo, Turn finds the list empty                                                    | `turn` does not await `records.current.landed()`: KeyUndo after one unrecorded keystroke fails, the undo found the list empty at once                                                 |
| The repaint after an undo skips a box whose keystroke is still sending                                             | 38 states, `UndoRestoresBefore`: TypeText, RecordText, KeyUndo, Turn leaves the box showing the letter                                                           | `liveRepaint` skips a busy box for the person too: Turn fails, the box kept the new text                                                                                              |
| The undo does not wait for the notes records                                                                       | 19 states, `NoUndoOnMissing`: TypeNotes, KeyUndo, Turn finds the list empty                                                                                      | `useNotes` does not hold `records`: KeyUndo after one unrecorded notes edit fails, the undo found the list empty at once                                                              |
| A notes edit records only once the notes edit before it reached the server, and the undo waits for the notes queue | 188 states, `UndoTakesLastTyped`: TypeNotes, TypeNotes, TypeText, RecordNotes, RecordText, UploadNotes, RecordNotes, UploadNotes, KeyUndo, Turn undoes the notes | `useNotes` records in a queue behind each notes upload: RecordNotes for the second notes letter fails, its record never went out, and so does the test that types notes then the text |
| Ctrl+Z in the notes field goes to the field's own undo, which takes back one letter at a time                      | not modelled: the model's `KeyUndo` asks for the person's undo wherever the person typed last                                                                    | the notes field without `data-person-undo`: KeyUndo after one notes edit fails, the key went to the browser                                                                           |
| The notes field keeps its own copy while it has the focus                                                          | not modelled: `ShownIsDeck` on `shownN`                                                                                                                          | `NotesBar` follows `text` only without the focus: the first TypeNotes fails, the field kept the old notes                                                                             |

Without `NoUndoOnMissing` and `TurnLands`, the model with either wait removed passed the other properties (376 and 408 states, with the old notes queue): a missing record makes Ctrl+Z do nothing or say nothing changed, never land a wrong text, because `undoOf` lands only while the deck shows the entry's text.
