# What enforces each rule

Checks block gate or CI; review needs judgment.

| Rule | Enforced by |
| --- | --- |
| No comments, no lint suppressions | lint: `no-comments` and the comment scan |
| No raw hex, color mix, sized arbitrary class, blanket transition or destructive fill on text | lint: `no-raw` |
| Field edges have one owner | lint: `no-field-edge`; browser: `account.spec.ts` |
| No file or folder named `utils`, `helpers` or `common` | lint: the name scan |
| One word per idea: a word listed in `tooling/oxlint-plugin-airdesign/glossary.json` is replaced by the word it names | lint: the name scan reads the glossary. A line kept on purpose is listed there with a reason. It warns for now and blocks nothing |
| Product code takes the clock, random ids and temp folders as options: no read of `Date.now`, `Date()`, `new Date()`, `performance.now`, `Temporal.Now`, `Math.random`, `crypto.randomUUID`, `crypto.getRandomValues`, `tmpdir` or `TMPDIR`, except as the `??` or default-parameter fallback of an option | lint: `no-hidden-input`. It warns for now and blocks nothing |
| Only `packages/document` makes an `ElementId`: no type assertion to `ElementId` outside `packages/document/src` | lint: `no-element-id-cast`. It warns for now and blocks nothing |
| A package exposes only its `index.ts`, declares what it imports, and stays pure | `package-boundaries` step |
| A package's `index.ts` exports only names a caller outside the package, or a test through `index.ts`, uses | `unused-exports` step blocks gate and ci |
| Agent-written files over 5,000 tokens cannot grow; new files stay below it. A token is four bytes | `file-growth` step warns in the merge queue and blocks elsewhere |
| No hand-kept list of what a folder holds: `pnpm typecheck` reads `apps/` and `packages/`, `pnpm test:tooling` reads `scripts/`, and the spec replay reads `specs/` | the `tsconfig-references` step of `pnpm check` fails when the root `tsconfig.json` lists references |
| Unit tests run with nothing built: a test reads sources, never a package's `dist` | `scripts/source-only.mjs` makes vitest refuse to load any `apps/*/dist` or `packages/*/dist` file, so a test reading built output fails even after a build. `scripts/source-only.test.mjs` fails when a vitest project drops it. `pnpm check` runs `typecheck`, then `build` and `site-build`, because all write `dist` |
| Builds run serially: concurrent `tsc -b` writes leave shared declarations incomplete | `scripts/build-order.test.mjs` fails a `pnpm` command in `package.json` or a workflow that builds two projects with `--filter` and no `--workspace-concurrency=1`. The `journeys` build failed this way on main at a83f2535 |
| A state machine keeps its invariants | `model-check` step |
| Every spec has a code replay test or a listed exemption | `spec-coverage` step warns |
| Specs track covered declarations and their last synced digests in `specs/<topic>/covers.json` | The `spec-drift` step warns about changed or removed declarations. `--sync <topic>` records a new sync only after `pnpm check:specs <topic>` passed. |
| A broken spec property stays in `<Module>.known.cfg` beside an `it.fails` test | `pnpm check:specs` fails when a known config stops failing |
| Untouched PowerPoint content survives byte for byte; edits change only their parts and add no validator error | `pnpm check:pptx`: untouched bytes; Microsoft validator against original. With `ci`, it is the whole merge test: no PowerPoint hand check |
| Elements with no native PowerPoint form export as pictures; AirDesign looks come first | review; exporter and tests pending |
| Every lint rule has a test and is switched on | `lint-rules` step |
| Rule code in `tooling/` stays under 10 percent of product code | `lint-rules` step |
| Finished worktrees and branches are swept safely | `pnpm sweep` lists merged, closed and scratch work; `--apply` removes it. `scripts/worktrees.mjs` guards live processes, dirty files and 3-hour activity; tests cover each |
| Stashes are shared; recover only yours | `scripts/worktrees.mjs` warns on missing stash sources during `pnpm check`; read-only |
| Killed verify runs and test clusters are removed before new ones start; live processes are kept | `leftover-runs.test.mjs` and `leftover-clusters.test.ts` |
| An unmerged closed pull request's branch is deleted; one reopened for its fresh run keeps it | `closed-branch` waits 60 seconds and deletes only if the pull request is still closed, never `main` or `archive/` (`closed-branch.test.mjs`, PR 953) |
| Formatting preserves unstaged edits | `scripts/pre-commit.mjs` refuses unformatted partly staged files; `scripts/install-hooks.mjs` installs it |
| Browser/support imports resolve, including lazy entries | `test-imports` step. Computed targets need runtime checks |
| Cheap checks fail before taking a slot; gate takes none | `scripts/check.test.mjs`, `scripts/gate.test.mjs` |
| Run `pnpm gate` after your last edit, before every push | `pnpm gate` or `pnpm check` stamps it; `pre-push` refuses any other and names `pnpm land` (`scripts/checked.test.mjs`) |
| The gate runs reached unit files up to 40. Above 40 or for a full-suite plan, it runs changed unit files only | `scripts/gate.test.mjs` checks selection. Isolation makes the subset sound. ci runs all files. `scripts/selected-unit-tests.test.mjs` checks exact paths |
| A commit whose test failed is not pushed; a failed test is load only when it passes alone | `pnpm gate` and `pnpm check` withhold the stamp if step `unit-tests` fails. `pnpm land` stamps after the alone rerun (`scripts/land-check.mjs`) |
| PR titles and bodies follow the rules; name the areas | `pnpm land` refuses bad titles and bodies before the gate; `bar` fails on local paths, placeholders or commits absent from branch and main (`scripts/pr-body.mjs`). Missing Evidence warns. `commit-titles` warns; `bar` adds title and area labels |
| A commit is authored by the owner and has no `Co-authored-by` trailer or AI attribution line; a PR body has no "Generated with" line | `scripts/commit-authors.mjs` refuses the commit. `pnpm land` refuses that line in a body file or an open pull request before the gate and names it |
| A PR is in the merge queue, not only believed to be | `pnpm land` reads the queue back and stops when the PR is neither queued nor armed (`scripts/merge-queue.mjs`) |
| A failed ci job is never rerun; one fresh run per head if it failed outside the diff | `pnpm land` prints if `main` moved (`land-report.mjs`); when only browser or journeys tests outside the diff fail, it comments and reopens or requeues (`fresh-run.mjs`). `ci` fails attempt 2+ |
| A conflict with `main` is found before the gate; no conflict marker is committed | `pnpm land` runs `git merge-tree` before the push. The `conflict-markers` step warns for now and blocks nothing |
| A pull request targets `main` | the `bar` check fails on any other base and names `pnpm land` as the fix; `pnpm land` moves an open pull request's base to `main` before the push |
| A pull request's title, body and base change through `pnpm land`, never `gh pr edit`, which fails here with the Projects (classic) error | `pnpm land --title` and `--body-file` set an open pull request's title and body through the REST endpoint (`scripts/pull-edit.mjs`). `scripts/land.test.mjs` fails when a line land prints tells the agent to run `gh pr edit` or `gh pr create` |
| A commit rebuilt from a stale tree does not undo other people's work: a branch does not put files back to content `main` has since replaced, unless its commit body says `Reverts: <path>` | `pnpm land` stops before the gate (`scripts/stale-tree.mjs`). The `restored-files` step warns for now and blocks nothing |
| A migration number is used once | the `migration-numbers` step of `pnpm check` compares the record with `origin/main` and names the next free number. It warns for now and blocks nothing; `pnpm land` stops on it |
| A dropped queue entry is seen | `pnpm land --watch` prints the queue run's failed tests and requeues only as a fresh run. The `queue-drop` job in `ci-failure-report.yml` comments on the dropped PR with failed jobs, steps, tests and run link, and queues nothing (`queue-drop.test.mjs`) |
| A crash of the failure report shows red, never green. The report is not a required check, so a red run blocks no merge (`main` requires only `ci`) | `scripts/ci-failure-report.test.mjs` fails when a step of the `ci-failure-report` job sets `continue-on-error` |
| The local check queue keeps its rules | `CHECK-QUEUE.md` lists each rule of the machine lock and what holds it |
| Long jobs survive the agent call ending | `pnpm detach` starts a session; `--wait` drains its log and returns its status (`scripts/detach.test.mjs`) |
| A local browser run uses at most 4 workers | `playwright.config.ts` sets the count through `workerLimit` in `tests/browser-workers.ts`, and the `globalSetup` in `tests/browser/launch.ts` stops a larger `--workers` with one line unless `AIRDESIGN_BROWSER_WORKERS` is set. ci keeps Playwright's default, two workers on its four cores: four made each test about 1.7 times slower |
| A ci job that runs the database tests, the PowerPoint check, corpus or paint fidelity gets PostgreSQL from the one action before it runs them | `scripts/ci-postgres.test.mjs` fails a check, pptx, corpus, paint-fidelity, journeys or mutation job that has no `./.github/actions/postgres` step first |
| A ci job that replays the TLA+ specs gets the TLA+ tools from the one action before it runs them | `scripts/ci-tla.test.mjs` finds each job in `.github/workflows` that runs `pnpm check --part` or the mutation check, and fails when the job has no `./.github/actions/tla` step before it, when a workflow downloads the jar itself, or when the action's cache key or hash differs from the jar `scripts/check-specs.mjs` accepts |
| Picture uploads keep concurrent additions | `media.ts` uses `changeSlot`; `media.test.ts` overlaps adds and uploads |
| A test file sees only the rows it wrote | `postgresInfo` in `apps/api/src/harness.ts` gives each `apps/api` test file its own database, cloned from the template the globalSetup prepares; `scripts/vitest-api-database.mjs` drops it after each file; `isolation.test.ts` fails when it sees another file's rows |
| Each unit test file has its own Vitest worker environment and module state | `vitest.config.mts` enables isolation; `scripts/test-isolation.test.mjs` checks every resolved project |
| A trait's stored fields never change without a higher stamp, so the stored format rises and an older tab reloads before it reads a row it cannot | `packages/document/src/trait-format.test.ts` hashes each trait's fields against its stamp and keeps every shape a stamp ever had, so a changed field names the version to write |
| No stored register holds PR 478's `slide: "background"` command, and none of its colours is lost | `apps/api/src/background-rewrite.test.ts` turns that shape into fill rows and drops `deck.background_backup`. `packages/live/src/cache.slide.test.ts` shows it as a fill. `packages/catalog/src/slide-wire.test.ts` refuses it on commit |
| An authorable trait field is live in every authoring layer or in none: its codec, its agent description and example, its control label, a read of it from the export, and a judged PowerPoint case | `pnpm typecheck` and the `build` step fail when a declared field has no entry in `traitXml`, `traitWire`, `traitControls` or the probes of `apps/web/src/trait-parity.test.ts`, using mapped trait/field types, or when an agent example is invalid. The parity test lands each field's example as an agent via `edit_deck`'s reader and as a person, exports it, reads it back, paints it, undoes it to the original bytes, wants a `scripts/pptx-cases` entry whose `covers` names it, and wants words for every label, description and option. Its `control` probe sends the example through the design panel's row, `planChange` and the person's queue. Its `inherit` probe sends `null` through the row of a field its trait declares `inheritable` and wants the inherited value in the export, and the copy probe wants that row's reset words. An alpha field has no row: the test sends `{ opacity: 60 }` as an agent and through the Opacity row to one element of each kind with an alpha field, and wants each such field to read 60 % in the export, paint, undo to the original bytes and be covered by a case. `table-authoring.test.ts` checks refusals; `cache.table.test.ts` checks saved-table replay. `apps/web/src/control-kinds.test.ts` wants a component and a `tests/browser/control-<kind>.spec.ts` for every control kind a field uses, inside a union, a record or a list too |
| Every control kind a trait field uses has one component and one browser test | `apps/web/src/control-kinds.test.ts` maps every declared field and text input to its control kind and fails when the kind has no entry in `controlViews` or no `tests/browser/control-<kind>.spec.ts` |
| Every gesture in the editor has one row in the gesture table and a browser test | `apps/web/src/gesture-coverage.test.ts` reads every `tests/browser/*.spec.ts` and fails for each row of `gestures` in `packages/render/src/gestures.ts` that no `covers(...)` call names, and for a `covers(...)` id that is not a row. `packages/render/src/gestures.test.ts` fails when a press of one row reads as another row where both work |
| A drag paints once a frame and leaves the filmstrip and design panel alone until it lands | `tests/browser/drag-feel.spec.ts`; its `drag-frame` and `drag-delay` warn over their limit |
| A shipped migration is never edited; a change is a new migration | `apps/api/src/frozen-migrations.test.ts` checks each migration's exact sql against `apps/api/src/frozen-migrations.json`, and `scripts/frozen-migrations.mjs` only appends |
| Tests never retry | Vitest and Playwright set no retries; ci fails a rerun; a fresh run is attempt 1 (`ci-parts.test.mjs`) |
| `main` takes only a commit that passed `ci` on top of the latest `main` | branch protection and the merge queue |
| On PRs the design scans run in a job per 200 states, `design-findings` judges all their reports, and other browser tests run in four shards | `--part=design --shard=<n>/<total>` sweeps its share (`look/states.test.mjs`), `--part=browser --shard=<n>/4` skips the scans, `--part=findings` fails on a lost report. `design-shards.test.mjs` and `ci-parts.test.mjs` hold the jobs |
| Push ci reuses only successful queue ci for the exact main commit, independent of performance caches | `scripts/ci-queued.test.mjs` runs the action on absent, failed, different-SHA, wrong-event, wrong-workflow and failed lookups; all keep work required. Main, side, browser, corpus and pptx skip on verified success; queue corpus covers pptx. Design stays PR-only and paint stays independent (`scripts/ci-parts.test.mjs`) |
| Queue validator answers reach main even on a render-cache miss; cache handoffs cannot certify a commit | `scripts/ci-corpus.test.mjs` checks both shard artifacts and missing/empty downloads. `scripts/ci-parts.test.mjs` requires approved-run promotion and optional cache operations. Small spec results transfer on a miss; render caches retain restore/save without forcing checks to warm them |
| Journeys judge a PR before the merge queue | `ci` calls `journeys.yml` on PRs and in the queue and requires success or skipped. The reusable workflow keeps manual dispatch, has no push trigger and opens or closes no issues (`scripts/ci-parts.test.mjs`) |
| Production passes the journey after every deploy | `production-journey.yml` runs after each successful `deploy` run. | A PR that lowers the bar is seen by the owner: a raised limit, moved goal, metric off its goal, removed metric, check step, job, spec invariant, case, deck or caught break, new skip, step made a warning or local, lint or type rule turned down | `bar` labels the PR `lowers-the-bar` (`scripts/bar-files.mjs`) and fails until an agent that did not write it countersigns its head (`scripts/countersign.mjs`) |
| Planted faults on changed code are reported | the `mutation` job, which warns about survivors and blocks nothing. Stryker leaves every symlink git tracks out of its sandbox (`linkedPaths` in `scripts/check-mutation.mjs`), and a crash fails the job while a run that hits its time limit only warns (`scripts/ci-crashes.test.mjs`) |
